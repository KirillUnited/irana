# Три правила для мобильной версии:

1. Интерактивные элементы (Шоукейс проектов): На десктопе при наведении (hover) на проект обычно всплывает описание. На мобилках hover не работает. Укажите ИИ, чтобы на смартфонах текст был виден сразу или открывался по тапу.
2. Форма контактов: Поля ввода (Input из shadcn) на мобильном должны иметь размер шрифта не менее text-base (16px), иначе iOS будет автоматически приближать экран при фокусе на поле, что ломает UX.
3. Размер тач-зон: Все мобильные кнопки и ссылки должны быть высотой минимум h-11 (около 44px), чтобы по ним было удобно попадать пальцем.
